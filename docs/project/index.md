# This project

The manual for *this* repository, optimized for Ctrl-F: the full command surface and the local
automation it registers. Nothing here teaches — that is what [tutorials](../tutorials/index.md)
and [explanations](../explanation/index.md) are for; these pages answer precise questions with
stable headings. The vocabulary lives one level up, in the bundle's own
[glossary](../glossary.md).

## Pages

- [Command catalog](commands.md) — all forty-one `/quenching:*` commands by front, one line
  each, plus the `cq` rail's exit-code contract.
- [Automation registry](automation.md) — this repository's **own** local Claude Code command
  surface, derived from `.claude/commands/`; its table is regenerated by
  `cq components registry reindex`.
- [Repository layout](layout.md) — what sits where in this checkout, directory by directory,
  and which command owns each surface.
