## Problem

- `assets/references/specs-develop/specs-surface.md:41` lista `cq specs selftest`, e `artifacts.md:244` usa esse comando como exemplo de `verify:` com `cwd:`. `specs/commands/cli.py:12` diz que `selftest` não é mais subparser (a prova foi para `tests/test_specs_assets.py`). **Reproduzido** (grep).
- `assets/references/specs-develop/report-mold.md:49` cita `commands/docs/status.md`, e `components-command-eval/evaluation.md:84` cita `commands/docs/add.md`. O diretório `commands/docs/` não existe. **Reproduzido.**
- `citation-check.sh` (no gate) não pegou nenhum dos quatro.
- Consequência: quem copia o exemplo de `verify:` recebe erro de argparse e a task nunca fecha. Quem edita o report mold não acha a fonte da regra.

Candidato `C04` do mapa `.quenching/improve/2026-10-07/specs-flow/04-references-citam-verbo-e-caminhos-removidos.md` (efêmero); a proposta, os riscos e a validação estão no epic 1145 e no mapa.

## Proposal

- `specs-surface.md` no longer lists `cq specs selftest`, a verb the CLI does not have.
- `artifacts.md` no longer uses `cq specs selftest` as its example of a `cwd:`-bound `verify:`.
- `report-mold.md` and `components-command-eval/evaluation.md` cite paths that exist (`commands/knowledge/status.md`, `commands/knowledge/add.md`) instead of `commands/docs/`.

## Out of Scope

- Extending `citation-check.sh` to catch dead verbs or the old `commands/docs/` path: a separate detector, deferred to `## Open Decisions`.
- Rewording the `/docs/` standards that mention `commands/docs/` historically (`command-surface.md`, `prose-deletion-seams.md`): they narrate history ("then still `commands/docs/`") and are not citations.

## Impact

### Standards this spec will write into docs/standards/

- none — a citation fix declares no standard.

### Product code this spec expects to touch

- `plugins/quenching/assets/references/specs-develop/specs-surface.md` — drop the selftest row
- `plugins/quenching/assets/references/specs-develop/artifacts.md` — generic `cwd:` example
- `plugins/quenching/assets/references/specs-develop/report-mold.md` — live path
- `plugins/quenching/assets/references/components-command-eval/evaluation.md` — live path

## Validation

- `grep -rn "specs selftest" plugins/quenching/assets/references` prints nothing.
- `grep -rn "commands/docs/" plugins/quenching/assets/references` prints nothing.
- `bash scripts/verify_repo.sh` exits 0.

## Design

Decision: delete the dead row and generalize the `cwd:` example, rather than inventing a replacement verb. Durable rule: a reference names only verbs the CLI parses and paths that exist in the tree. `cli.py:12` records that `selftest` is no longer a subparser; `commands/knowledge/` is the live successor of `commands/docs/`.

### Mapa de dependências

2026-10-07, from grep over assets, commands, docs and scripts: the only citations are the four lines above; `citation-check.sh:130` and `lint.py:697` mention `commands/docs/` as prose/examples inside tooling and are not references to a file; the two `/docs/standards/` hits are historical narration. Nothing breaks if the four lines change.

## Alternatives Considered

- Restore `cq specs selftest` as a verb: rejected, the proof moved to `tests/test_specs_assets.py` on purpose.
- Leave the historical paths and add a redirect note: rejected, it keeps dead citations in executable prose.

## Open Decisions

- Whether `citation-check.sh` should learn to flag dead `cq` verbs and removed command paths. Decided by whether the epic 1145 map ranks it; this spec does not block on it.

## Risks

- A citing body loads a changed reference and reads differently: low, the edits are one line each and the example keeps its meaning.
- `evals/docs/add/` mirror statement in `evaluation.md` becomes `evals/knowledge/add/`; if that folder does not exist the prose is still an illustration of the mirroring rule. ACCEPTED — the sentence illustrates a path mapping.
