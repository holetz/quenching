## Problem

O `knowledge:status` reporta "the payload's `controls` block" de um payload que nunca coleta. Verificação independente (`../resume-map-prose-verify.json`, item 4, HEAD e7bc280f): `plugins/quenching/commands/knowledge/status.md:104` cita o bloco `controls`, mas a coleta (`:54-55`) só chama `validate`, que devolve uma lista de findings. `cq knowledge status docs --json` sai 0 com as chaves `applicable,controls,density,errors,findingCodes,findings,ok,root,state,warnings`. Origem: o commit `0c853d77` (1638 2.5) mudou `cli.py` e `status.md` sem acrescentar a coleta.

Consequência: o relatório de controles não tem fonte e é preenchido por inferência.

Escopo (decisão do dono): coletar `cq knowledge status docs --json` (superconjunto do `validate`) mantendo o `--activity`, para que o "Cheap by construction" de uma chamada (`:34`) continue valendo. O método de densidade atual (`Glob`) fica como está: o campo `density` do payload não passa a ser a fonte. Arquivos: `commands/knowledge/status.md` e um teste de prosa em `plugins/quenching/tests/test_align_contract.py`.

Aceite: o passo de coleta chama `cq knowledge status docs --json`, o relatório de controles cita só esse payload e a densidade continua pelo `Glob`; `python3 -m unittest discover -s plugins/quenching/tests -p test_align_contract.py` e `bash scripts/verify_repo.sh` saem com 0.
