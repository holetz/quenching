## Problem

O `cq git audit --gate` da 1278 (#1282) roda `bash scripts/verify_repo.sh` com `cwd` na worktree auditada (`plugins/quenching/assets/bin/quenching/git/audit.py:56-61`, conferir o caminho): uma edição não commitada do script passou a dar exit 0 contra exit 1 na base, criou um arquivo e tentou `git branch -D` sob o verifier (reproduzido em 2026-10-08). Sem `--gate`, um `filter.<x>.clean` na config do repositório junto com o `.gitattributes` da branch executou durante o `git status`, contra a docstring (`audit.py:7-8`) que diz que a config do repo não executa nada. E `agents/verifier.md:27` ("accept the exit code the runner reported") contradiz `verifier.md:9-10` e `agents/orchestrator.md:62-63`. A 1278 registrou o risco do `--gate` como decisão aberta.

Consequência: a própria branch auditada certifica o gate, e o verifier "só leitura" executa código com os direitos do usuário.

## Proposal

**Decidido com o humano em 2026-10-08: o CI certifica o gate, antes do merge.**

1. `cq git audit` perde o `--gate` (`GATE_SCRIPT`, `_gate`, a frase da docstring): o verifier não executa código. O check 3 de `agents/verifier.md` registra o exit que o runner reportou como alegação, não como veredito, e deixa de contradizer `verifier.md:9-10` e `agents/orchestrator.md:62-63`.
2. O passo `merge` do git-steward só mergeia com `gh pr checks <pr>` todo verde (esperando, com teto). Check vermelho → `STATE: failed`. Nenhum check configurado, ou pendente além do teto → `STATE: blocked`, `NOTE: needs-human: nenhum CI certificou o gate`. `agents/orchestrator.md` §Accept/Merge e `agents/git-steward.md` dizem isso.
3. O `git status` do audit não executa a config do repositório: neutralizar, antes da leitura, os drivers que a config declara e que o status pode rodar (`filter.<x>.clean`/`smudge`/`process`, e o que mais o teste revelar), com teste reproduzindo `filter.<x>.clean` na config + `.gitattributes` da branch (ver `/tmp/claude-1000/-home-unicred-Projetos-claude-quenching/a284eb01-1fc3-4a7f-ae95-abf7651b3d1b/scratchpad/review7/`, `PWNED_status`). Se for impossível neutralizar, a docstring deixa de prometer e o risco vai para `## Risks`.

A 1292 transforma o merge num verbo `cq git` de argv fixo e herda a exigência do item 2.
