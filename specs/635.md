## Problem

Na conclusão da spec 628 (26/11/2026), `git_pr_merge(url=…/pull/634, spec=628)` mesclou o PR e a spec já aparecia em `archive` com `outcome: done`; o `specs_reconcile(write=true)` seguinte não trouxe linha para a 628 e o slot `quenching-slot-5` ficou `locked` na branch `plan/628-ci-coverage-python-novo` já mesclada. O conclude.md §8 promete que o reconcile libera o slot da linha que arquiva; como o arquivamento aconteceu antes, nenhuma linha liberou o slot. Foi preciso um `git_worktree_release` manual.

Correção mínima proposta: o reconcile (ou o próprio `git_pr_merge` com `spec`) libera o slot de uma spec arquivada cuja branch mesclada ainda está num slot.

**Insumos**

- .claude/skills/quenching-specs/references/conclude.md §8 (slot liberado pelo reconcile)
- `git worktree list` depois do reconcile: `~/Projetos/quenching-slot-5 4a2c7f924 [plan/628-ci-coverage-python-novo] locked`
- spec 628, passo 8 do conclude; PR #634
