## Problem

O `--spec` do `cq git worktree add` deixou de recusar um branch com o id de OUTRA spec: `cq git worktree add --spec 1 --branch plan/2-beta …` sai `ok: true` e grava `work=plan/2-beta`, e a spec 2 também passa a ser dona do branch; o cq de 49ed50e2 recusava com `git-worktree-spec-head-mismatch` (`/tmp/claude-1000/-home-unicred-Projetos-claude-quenching/a284eb01-1fc3-4a7f-ae95-abf7651b3d1b/scratchpad/review16/wt1`). Onde: `plugins/quenching/assets/bin/quenching/git/pull.py:205-206`, `plugins/quenching/assets/bin/quenching/git/worktree.py:155`. Direção: recusar quando o nome casa `(?:.+/)?(\d+)-` com um id diferente; `feat/PROJ-77-x` segue aceito.
