## Problem

Reproduzido pela revisão de correção do épico 1560 (2026-10-12), em `main` 7650b139. A telemetria do orchestrator
(`plugins/quenching/agents/orchestrator.md:89`) usa `cq components session cost --nested`, que soma os descendentes
de **todos** os orchestrators da sessão. A opção exata, `--descendants-of <agentId>`, não está ao alcance do
orchestrator: o `env` de um subagente só expõe `CLAUDE_CODE_SESSION_ID`, e um prefixo do id dá `se-no-requests`.
Nesta sessão de autopilot, com 5 orchestrators, `--nested` dá 801 req e 284.937 de output. Por orchestrator, o
`--descendants-of` com id completo dá 75, 261, 195, 147 e 123 req, que somam exatamente 801. O de 75 req reportaria
10,7× o próprio custo. A sessão `a284eb01` tem 22 orchestrators.

Consequência: todo relatório de custo de um autopilot com mais de uma rodada sai inflado, e o relatório final do
condutor não consegue separar o custo por épico. A auditoria de tipos não é afetada, porque todos têm a mesma lista
`Agent(...)`. A correção fica na ferramenta: um jeito de o orchestrator se identificar ou recortar seus descendentes,
por exemplo pelo início da sua janela. Quem mede e o que o relatório contém não mudam.

## Proposal

- `cq components session cost` accepts `--since <ISO-8601>` and counts only the requests whose record `timestamp` is at or after it; it composes with `--nested` and is mutually compatible with `--descendants-of`.
- An orchestrator can cost only its own window without knowing its agent id: `--nested --since <start of its run>` no longer includes the descendants of earlier orchestrators of the same session.
- `plugins/quenching/agents/orchestrator.md` tells the orchestrator to note its start (`date -u`) once and pass it as `--since` in the telemetry call.
- A request with no parsable `timestamp` is never counted under `--since` (it cannot be proved inside the window) and is reported as an anomaly.

## Out of Scope

- Changing who measures or what the report contains: the orchestrator still measures, the report shape is unchanged.
- Discovering the caller's own agent id: the harness exposes only the session id to a subagent, so this is not reachable from the tool.
- An upper bound (`--until`): the telemetry runs at the end of the orchestrator's window, so it adds nothing today.
- The agent-type audit, which is unaffected (all orchestrators share one `Agent(...)` list).

- With two sequential orchestrators in one fixture session, `--nested --since <second start>` counts only the second one's descendants.

## Design

- Rule: the window is the discriminator the tool can honour without the caller's identity. Request timestamps are in every transcript record; the orchestrator can read the clock once at start.
- Filtering is per request (not per agent file) so an agent that straddles the boundary is split correctly.
- Timestamps compare as parsed datetimes (ISO-8601, `Z` accepted), never as strings; an unparsable `--since` is exit 2.
- Alternatives weighed inside the design: self-detecting the caller from the transcript's pending `tool_use` (fragile, depends on flush order); a prefix match of `--descendants-of` (the orchestrator has no id to take a prefix from).
- Limit: a straggler of an earlier orchestrator still running after the next one starts would be counted; autopilot rounds are sequential, so this is accepted.

## Alternatives Considered

- Exposing the agent id to the subagent env: outside this repo (harness), unreachable.
- Infer the calling orchestrator inside the tool: rejected as fragile (see Design).
- Per-orchestrator accounting by the conductor: changes who measures, which the epic rules out.

## Open Decisions

- none — the window source (`date -u` at orchestrator start) is decided; the why-now is stated in the Problem (every multi-round autopilot report is inflated).

## Risks

- A straggler of the previous orchestrator is counted in the next window. ACCEPTED — rounds are sequential.
- The orchestrator forgets to note its start: the call falls back to plain `--nested` and over-reports as today. Mitigation: the instruction sits in the same step-8 sentence as the call.
- Clock skew between the harness timestamps and `date -u`: both are UTC wall clock on one machine.
