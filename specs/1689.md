## Problem

O modo incremental `--desde <ref>` de `/quenching:knowledge:documentation:produce` precisa de git, mas o comando não concede git.

Evidência:

- `plugins/quenching/commands/knowledge/documentation/produce.md:5`: `allowed-tools: Bash(cq:*), Read, Grep, Glob, Bash(python3:*), Bash(py:*), Skill` — nenhum `Bash(git:*)`.
- `plugins/quenching/commands/knowledge/documentation/produce.md:59-61` (passo 1): com `--desde <ref>`, valida o ref com `git rev-parse` e precisa do conjunto de arquivos alterados para passar a plan, write e review; ref inválido cai no pipeline completo.

Consequência: numa sessão em modo deny, `git rev-parse` é negado, o comando trata como ref inválido e o run incremental degrada em silêncio para o pipeline completo — o custo que o `--desde` existe para evitar.

**Decisão do dono necessária:** a correção amplia `allowed-tools` (por exemplo `Bash(git rev-parse:*)` e `Bash(git diff:*)`) ou cria um verbo `cq` que resolva o ref e o conjunto alterado. Ampliar a superfície de permissões de um comando é decisão do humano dono do plugin; o autopilot não a toma nem a força.
