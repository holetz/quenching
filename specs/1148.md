## Problem

- `docs/index.md:74` (`# 6.3.0`) e `docs/tutorials/getting-started.md:79` (`6.3.0` como saída esperada), enquanto `plugin.json` diz 6.4.0. **Reproduzido** (grep).
- `docs/explanation/operating-model.md:12` tem `source: … §The 56 commands`, mas o README do plugin tem `## The 57 commands`. **Reproduzido.**
- Consequência: o tutorial usa a versão como prova de instalação, então um adotante vê 6.4.0 e acha que falhou. O `source:` aponta para um cabeçalho inexistente. O release (lockstep de quatro artefatos) não toca essas strings, então isso volta a cada release.
