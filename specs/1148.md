## Problem

- `docs/index.md:74` (`# 6.3.0`) e `docs/tutorials/getting-started.md:79` (`6.3.0` como saída esperada), enquanto `plugin.json` diz 6.4.0. **Reproduzido** (grep).
- `docs/explanation/operating-model.md:12` tem `source: … §The 56 commands`, mas o README do plugin tem `## The 57 commands`. **Reproduzido.**
- Consequência: o tutorial usa a versão como prova de instalação, então um adotante vê 6.4.0 e acha que falhou. O `source:` aponta para um cabeçalho inexistente. O release (lockstep de quatro artefatos) não toca essas strings, então isso volta a cada release.

Candidato `C05` do mapa `.quenching/improve/2026-10-07/knowledge/05-versao-e-contagem-congeladas-nas-docs.md` (efêmero); a proposta, os riscos e a validação estão no epic 1145 e no mapa.

## Proposal

- `docs/index.md` and `docs/tutorials/getting-started.md` no longer carry a literal plugin version: the quick start and the expected output say the command prints the plugin's version.
- The `source:` of `docs/explanation/operating-model.md` cites `§The 57 commands`, a heading that exists in `plugins/quenching/README.md`.
- `grep -rn '6\.3\.0' docs/` is empty, and a future release cannot leave a stale version literal in these two pages.

## Out of Scope

- Making the validator resolve `source: §heading` against the cited file — a separate tool change, parked as a discovery.
- Adding the docs lines to the `/release` four-artifact lockstep — ruled out: version-free text removes the need.
- Rewriting the tutorial beyond the version literal.
- Rewording the `source:` to drop the count from the heading — the README heading is not ours to change here.

## Impact

### Standards this spec will write into docs/standards/

### Product code this spec expects to touch

## Validation

- `grep -rn '6\.3\.0' docs/` exits 1 (no match), run before the fix it exits 0.
- `grep -c '§The 57 commands' docs/explanation/operating-model.md` prints 1 and `grep -c '^## The 57 commands' plugins/quenching/README.md` prints 1.
- `bash scripts/verify_repo.sh` exits 0.

## Design

Decision (settled 2026-10-07 by the human, recorded in the candidate map): replace the literal with text that does not age, instead of widening the release lockstep. Rationale: the lockstep is four artifacts by contract, and every extra string it tracks is another way for a release to fail; prose that names no number cannot go stale.

The tutorial keeps its role as an install check: the reader is told to expect one line holding the plugin's version, to compare against what they installed.

The `source:` fix cites the heading as it exists today. The count in that heading will move again; that recurrence is the validator's gap, parked as a discovery rather than solved here.
