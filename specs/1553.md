## Problem

Reproduzido pela revisão de correção do épico 1546 (2026-10-11), em `main` 5b93edfa. Depois da #1548 (spec 1542),
o texto "quatro artefatos" continua em:
- `docs/glossary.md:359` ("the four version strings a release must bump together");
- `docs/project/layout.md:43` ("one of four artifacts kept in version lockstep");
- `docs/standards/architecture/specs-reader-plugin.md:47`, que contradiz `versioning-release.md:59-60` ao dizer que
  o padrão do marketplace troca só o primeiro `"version"`;
- `docs/standards/workflows/retiring-a-standard.md:58` ("The four-artifact lockstep");
- `docs/decisions/0005-glossary-long-forms.md:229` ("no automated check asserts the four agree"), quando
  `test_specs_release.py` já faz essa checagem;
- os comentários em `specs/release.py:20-22` e `tests/test_specs_release.py:2,6-7`.
O código (`release.py:27-35`) lista 7 artefatos, entre eles o marketplace como `jsonall`.

Consequência: o glossário e os padrões contradizem o código do release. Quem consulta o lockstep confere uma lista
errada. Os ADRs são registro histórico, então ali se acrescenta um ponteiro ou nota, sem reescrever a decisão.
