## Problem

Entrada com barra final em `regenerablePaths` perde a âncora na raiz: com `regenerablePaths: ["data/"]` e `secrets/` ignorado, `cq git worktree retire` sai `ok: true` e apaga `secrets/data/creds.env` (`/tmp/claude-1000/-home-unicred-Projetos-claude-quenching/a284eb01-1fc3-4a7f-ae95-abf7651b3d1b/scratchpad/review14/fx/R1`). Onde: `plugins/quenching/assets/bin/quenching/git/worktree.py:210` (o `normpath` tira a barra), `:223`.

Origem: fila da rodada 6 do autopilot de 2026-10-08 (`.quenching/autopilot/2026-10-08/round6-queue.md`), item A7, da revisão de correção opus da rodada 5 (épico 1403).

## Proposal

- An entry of `shared.regenerablePaths` written with a trailing slash (`data/`) names that path from the repo root only, never the same name at any depth.
- `cq git worktree retire` with `regenerablePaths: ["data/"]` and an ignored `secrets/data/creds.env` stands (exit 1, `ignored` lists it) instead of deleting it.
- The slash-less entry (`data`) keeps meaning that name at any depth.
- `plugin-configuration.md` states the trailing-slash rule.

## Out of Scope

- Changing how slash-less or inner-slash entries match: they already behave as documented.
- Widening any grant, hook or CI: not needed.

## Impact

### Product code this spec expects to touch

- `plugins/quenching/assets/bin/quenching/git/worktree.py` — `_regenerable_paths` and `_is_regenerable`
- `plugins/quenching/tests/test_git.py` — a test beside the other retire tests
- `plugins/quenching/assets/references/specs-align/plugin-configuration.md` — the row for `shared.regenerablePaths`
- generated mirrors under `plugins/quenching-codex/`

## Validation

- `python3 -m unittest discover -s plugins/quenching/tests -p test_git.py` exits 0, including the new test, which fails before the fix.
- `bash scripts/verify_repo.sh` exits 0.

## Design

- `_regenerable_paths` uses `os.path.normpath`, which drops the trailing slash, so `data/` becomes `data` and matches at any depth. Rule: a trailing slash survives normalisation and marks the entry as root-anchored.
- `_is_regenerable` treats a rule that has an inner separator or a trailing one as anchored; width is computed from the rule without the trailing slash. Alternative weighed: rejecting `data/` as invalid; rejected because it silently changes the config of existing users into a refusal.

## Alternatives Considered

- Document that trailing slashes are ignored: rejected, the entry's natural reading is root-anchored and the failure deletes ignored files.

## Open Decisions

- none — the behaviour follows the entry's plain reading and the issue's report.

## Risks

- An existing `data/` entry that relied on any-depth matching now leaves such files standing at retire: ACCEPTED, the failure is a refusal that `--discard-ignored` resolves, never a deletion.

## Handoff

Both tasks committed; fix anchors trailing-slash regenerablePaths entries at the root. Remaining: conclude.
