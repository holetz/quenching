## Problem

O `guion` é um repositório público do dono: um dashboard de RPA em Flask com tema AdminLTE. Ele foi publicado já alinhado pela frente opensource, mas três itens de vitrine ficaram de fora e só foram notados numa revisão manual em 2026-10-18:

1. **Sem imagem da interface.** O README não tem nenhum print ou GIF. Para um produto com UI, é o que mais convence quem avalia o repo.
2. **Estatística de linguagem errada.** O GitHub classificava o projeto como JavaScript (~11,6 MB) por causa do tema e dos plugins vendorizados em `apps/static/assets/`, quando o código próprio é Python. Isso foi corrigido à mão com `.gitattributes` (`linguist-vendored` nos assets e `linguist-detectable=false` nos templates HTML), em holetz/guion#1.
3. **Sem topics no forge.**

O alinhamento do projeto já pergunta pela identidade visual: o `design:align` converge `/.design/`, o brand pack e os assets. Mas nenhuma frente fecha esses itens no README público. O README como documentação é da frente `knowledge`, porque o catálogo de controles dá a ela os controles DO, e `knowledge:documentation:plan` já lê o README como fonte. Descrição e topics são fatos do forge, e a 1962 os propõe como advisories do readiness.
## Proposal

- **Imagem da interface (design + knowledge)**: quando o projeto tem UI, o `design:align` pede ao dono um print ou GIF demonstrativo feito com **dados sintéticos** e o guarda como asset da marca. O `knowledge` (documentation plan/write) passa a exigir que o README público o referencie. Sem o asset, o achado é um advisory com a ação do dono, nunca uma imagem inventada.
- **Estatística de linguagem honesta**: um achado (dono a definir no `develop`: toolchain ou knowledge) quando diretórios vendorizados ou templates dominam a estatística de linguagem do forge. A correção proposta é um `.gitattributes` com `linguist-vendored` e `linguist-detectable`, aplicado com autorização.
- **Descrição e topics**: ficam com os advisories de vitrine da 1962 (opensource readiness, via provider), para que o mesmo controle não tenha dois donos. Esta spec só garante que o align do projeto chame aquele relatório.
- **Aceitação**: um alvo sintético no formato do `guion` (Flask + tema vendorizado + README sem imagem) produz os três achados. Depois da correção, nenhum achado sobra.
