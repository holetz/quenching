## Problem

Evidência (scout ses_de7f04b5, 2026-11-26): `cq specs promote --help` tem [--force] [--dry-run]; specs/mcp.py:393-397 `_w_promote` só repassa to/outcome e o schema (:489) não tem dry_run (o force ausente é intencional, :487). Consequência: o agente só descobre o gate de ## Outcome ou task aberta pela recusa exit 2. Proposta: expor dry_run (leitura) no schema e no wrapper, com teste.

## Proposal

- `specs_promote` no MCP passa a expor `dry_run` (booleano), repassado como `--dry-run` à CLI: o agente descobre o gate de `## Outcome` ou de task aberta sem mover a spec.
- `force` continua ausente do MCP (intencional, specs/mcp.py; decisão do épico 594).

## Out of Scope

- `force` no MCP: ausente de propósito; a spec 593 corrigiu a regra do store.
- Mudar o comportamento da CLI `--dry-run`.

## Impact

### Standards this spec will write into docs/standards/

- none — o contrato do MCP é descrito no README do produto, não em padrão.

### Product code this spec expects to touch

- `quenching/assets/bin/quenching/specs/mcp.py` — schema e wrapper de `specs_promote`
- `quenching/tests/test_specs_mcp.py` — teste de `dry_run`
- `quenching/README.md` — linha da tabela de tools

## Validation

- `python3 -m pytest quenching/tests/test_specs_mcp.py -q` passa, incluindo o teste novo: `dry_run` presente no schema, repassado como `--dry-run`, recusa por gate sem escrever, valor não booleano recusado.
- O teste novo não existe na base; o schema da base não tem `dry_run`.

## Design

- Decisão: `_w_promote` valida `dry_run` como booleano (`ToolArgs` caso contrário, igual a `full` em `_show`) e acrescenta `--dry-run`; o verbo segue no grupo WRITES sem confirmação. Evidência: `cq specs promote 597 --dry-run` recusa com `sp-gate-unmet` sem mover.
- Decisão do épico 594: 593 e 597 tocam specs/mcp.py em série; 593 já está mergeada, `force` permanece ausente.

## Alternatives Considered

- Tornar `dry_run` um verbo `specs_promote_check` separado: rejeitada; duplica o schema por uma flag que a CLI já tem.

## Open Decisions

- none — a forma foi decidida pelo épico 594.

## Risks

- Um agente tomar `dry_run: true` por uma promoção real. Mitigado: a resposta da CLI traz o gate e nada é movido; o teste prova que a fase não muda. ACCEPTED.
