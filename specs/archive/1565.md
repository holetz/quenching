## Design

### Autonomy policy

Authorized on 2026-10-11 by the human's invocation of `/quenching:specs:autopilot until dry`, the same one that
authorized epics 1522, 1534, 1546, 1554 and 1560. For every member, after a verifier PASS, the run may execute it
forced, push, open the PR and merge it into `main`, with no further confirmation, leaves included: the conductor sends
leaves to `git-steward` for the merge. No member widens a grant, a hook, CI, or a surface that executes code. A worker
that needs one returns `blocked` with `needs-human: alargamento`, and the conductor moves it to human epic 1527.

### Conductor decisions (as the delegated owner)

- Relevance: the opus correctness review of epic 1560 reproduced both members against `main` 32f7d222. The map was
  not run again: it found no candidate at 71f8f356, and the only code that changed since (`audit.py`, `cost.py`) was
  just reviewed.
- 1563 ties "kept" to discovery. A moved test's target counts only when it is where the gate discovers tests: the `-s`
  root and the `test*.py` pattern of `scripts/verify_repo.sh`, read from it or declared next to it, never guessed.
  Pairing prefers the same file name. Every regression fixture includes a target the gate does not discover.
- 1564 stays in the tool. The orchestrator gets a way to scope the cost to its own descendants, for example its start
  time with `--nested`, or an id it can actually read. It does not change who measures or what the report holds.
- Not taken as specs: a conductor agent's grandchild counted under `--nested` (synthetic only, absent from 5 real
  sessions), and merging two tests into one flagged by one-to-one pairing (by design).
