## Problem

`quenching/tests/test_run_evals.py::Containment::test_a_timeout_kills_the_grandchildren_too` failed once in the 18-minute affected gate of spec 281 (2026-11-24, slot 11, Windows) under xdist load. Alone it passes: 33.8s in the slot and 34.0s in a base worktree (main), so the 281 diff does not cause it; it is load-sensitive (a timeout/kill window in wall-clock time). A local gate red only on it is inconclusive, so green push CI is the only proof.

Minimal fix proposed: wait for the grandchild's death with a bounded poll instead of a fixed wall-clock window, or run the test serially (outside xdist).

**Insumos**

- quenching/tests/test_run_evals.py (class Containment, test test_a_timeout_kills_the_grandchildren_too)
- Command: QUENCHING_TEST_SCOPE=affected bash scripts/verify_repo.sh in the slot; failed once, isolated run passed twice (slot and base worktree).
- Spec 281, `## Discoveries` FLAKE line (conclude step 7, 2026-11-24).

## Proposal

- `test_a_timeout_kills_the_grandchildren_too` no longer depends on the machine being idle: the grandchild's delay leaves a wide margin over the timeout, and the final check waits until that delay has elapsed on the monotonic clock instead of a fixed `sleep(3)`.

## Out of Scope

- Changing `runner.invoke` or its kill logic — the failure is the test's wall-clock window, not the runner (the test passes alone, on the base).
- Running the test serially outside xdist — rejected, it changes the gate's layout for one test.

## Design

The grandchild fires at `sleep 2` while the timeout is 1s: under xdist load `invoke` can return after the 2s mark, so the grandchild touches the file before the kill lands (or the test's fixed 3s sleep observes a late kill). Decision: grandchild `sleep 5`, timeout 1, and after `invoke` the test sleeps until `start + 7` on `time.monotonic()`, then asserts the mark is absent. A margin of seconds on both sides is a rule of the test, not a poll: absence can only be proven by waiting out the window.

### Assumptions

- The flake is the load-sensitive 2s window — evidence: passes alone twice (spec 281 FLAKE line). Depends on: Validation.

## Alternatives Considered

- Run the test serially (outside xdist): rejected, touches the gate layout for one test.
- Poll for the grandchild's death: absence of a file cannot be polled to success; waiting out the window is the only proof.
