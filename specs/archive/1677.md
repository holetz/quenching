## Problem

A rodada paga da tarefa 5.3 da spec 1635 (2026-10-14, branch `plan/1635-module-extract` em deb5d2df) mediu o
roteamento com `plugins/quenching/assets/checks/functional-checks.sh --only 3` e saiu exit 1, com 0/5 frases no alvo
esperado. As cinco frases foram para o plugin instalado do usuário, `quenching@quenching` 6.4.0, que carregou ao
lado dos oito módulos gerados sob teste. As sessões `claude -p` da sonda partem de um settings vazio, mas os plugins
habilitados no perfil do usuário continuam carregando.

Consequência: a medição de paridade da modularização (1635) e de todo roteamento medido por `QUENCHING_FUNCTIONAL=1`
(que a release roda) depende do que está instalado na máquina de quem roda. Com o próprio quenching instalado, o
resultado é sempre falso e custa uma execução paga. A sessão sondada precisa de um diretório de configuração
descartável (por exemplo `CLAUDE_CONFIG_DIR` temporário, ou desabilitar explicitamente os plugins do usuário),
provado por um teste que falhe quando um plugin estranho carregar ao lado do alvo.

## Proposal

Restrict every functional-check session to project settings and reject a session whose startup plugin registry contains an external plugin besides the checkout under test. Preserve authentication and the existing write-tool denials. Cover all probes with an offline contaminated-CLI regression.

## Out of Scope

- Changing command bodies, routing descriptions, release policy or modularization.
- Copying credentials, modifying user settings, bypassing permissions or changing managed policy.
- Removing Claude Code built-in plugins.

## Design

Use `--setting-sources project` beside every explicit `--plugin-dir`. Each throwaway project already contains empty settings, so user/local enabled plugins and hooks are excluded without moving the authenticated profile. `claude --help` declares the source selector. A real startup probe on 2026-10-15 using `--max-turns 0` confirmed that context7, impeccable and quenching-hud disappeared with the selector, while the inline checkout and CLI builtins remained; both runs exited 0.

Inspect `system/init.plugins` before grading tools. Permit the expected checkout path and entries with path `builtin`; reject other entries as a measured failure. Missing or malformed startup inventory cannot prove isolation and is inconclusive. Existing anchoring and write denials remain in force. Strengthen the zero-cost selfcheck to require the selector for every session.
