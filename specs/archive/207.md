## Problem

`integrations/claude-hud/README.md:35` manda `/plugin install quenching-hud --marketplace holetz/claude-quenching`, mas esse repositório não existe: `git ls-remote https://github.com/holetz/claude-quenching HEAD` → `Repository not found`; o real é `holetz/quenching` (`git ls-remote` → 740c0c8da), como já usam o README do vitrine e `docs/standards/architecture/source-layout.md:29` (`/plugin marketplace add holetz/quenching`, `…@quenching`). Além disso `README.md:30` diz que o `cq` no PATH é "o que o plugin `quenching` garante", plugin aposentado pela ADR 0017 (`docs/decisions/0017-install-only-by-deploy.md`); `cq deploy` não põe `cq` no PATH (`integrations/claude-vitrine/hooks/cq.ts:85`).

Consequência: a instalação documentada do HUD falha sempre, e o pré-requisito do `cq` no PATH fica atribuído a algo que não existe. Correção: só o README — comando de instalação certo e o pré-requisito dito como é hoje (o HUD exige `cq` no PATH, que o deploy não provê). A resolução do lançador pelo hook é decisão do humano (spec 211).

## Proposal

- `integrations/claude-hud/README.md` §Instalação traz o par que funciona com o marketplace deste repositório: `/plugin marketplace add holetz/quenching` e `/plugin install quenching-hud@quenching` — o mesmo formato do README do vitrine e de `docs/standards/architecture/source-layout.md`.
- §Pré-requisito diz o pré-requisito como é hoje: o HUD chama `cq` no `PATH`; `cq deploy` instala `.agents/quenching/bin/cq` sem pô-lo no `PATH`, então cabe a quem instala o HUD deixar um `cq` alcançável. Nenhuma menção ao plugin `quenching` aposentado pela ADR 0017.
- O comportamento "sem `cq` a faixa some, sem erro" continua dito.

## Out of Scope

- Fazer o hook do HUD resolver o lançador `.agents/quenching/bin/cq` do repositório aberto (como `integrations/claude-vitrine/hooks/cq.ts` faz): decisão do dono no épico 212 manda isso ao épico humano 2206 (spec 211), porque alarga o que um hook executa.
- A linha de exemplo da faixa (`README.md:7`, nome de worktree `claude-quenching-1521-…`): é ilustração do formato, não instrução que falhe; fica como está.
- Receita de como pôr o `cq` no `PATH` (symlink, alias): depende de como o lançador resolve a raiz e de qual repositório o usuário quer; o README só afirma o fato.
