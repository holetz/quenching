## Design

Reproduced on main: `cq specs validate` errors on `archive/1315.md`, whose body reads `## Handoff` twice, the first empty (`parse_sections` keeps the first of a repeated heading). Two vectors let it through.

### Vector 1: a body spliced whole carries its own heading

`--scope current|global` (and the raw singular write when the stream does not open on a canonical heading) splices the body under `## Handoff` verbatim, so a body that starts with `## Handoff` writes the heading twice. `whole_body` drops a leading own-heading (the form a read prints, so it round-trips) and refuses any other unfenced `## ` line with `sp-write-nested-heading`, writing nothing.

### Vector 2: the archive gate ignores sections outside its entry gate

`promote` checked only the entry gate's sections, so a present-but-empty `## Handoff` archived. It now refuses any empty canonical section, matching `validate`'s phase-independent error.

## Alternatives Considered

- Only strip the duplicate heading: leaves the raw path with a foreign `## ` line opening a stray section, and leaves the archive gate blind to any other empty section.
- Fix only the archive gate: the malformed write would still land and only be caught at the end.

## Open Decisions

- none — both vectors are closed by the same rule (a whole body opens no section) plus the gate.

## Risks

- A raw write that used to open a stray section now refuses; `--fold` remains for strays already on disk. Mitigation: the refusal names the offending line.
