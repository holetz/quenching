## Problem

Visto em 2026-11-23 pelo runner da 267: `quenching/assets/bin/quenching/opensource/readiness.py:216` monta `"file://" + root` para o trufflehog. No Windows, `root` vem como `C:\...`, e a URL resultante não é um file URL válido. O caminho certo é `pathlib.Path(root).as_uri()`, com um teste.

## Proposal

- `_trufflehog` passes the scanner a valid file URL built with `pathlib.Path(root).as_uri()`, on every platform.
- The shallow-clone test builds its clone URL the same way.
- A test proves the URL handed to trufflehog is `Path(root).as_uri()` and carries no backslash.

## Out of Scope

- Other scanners (gitleaks, reuse): they take a path, not a URL, so they are not affected.
- Making the Windows platform gate green as a whole: other reds are tracked by the epic.

## Impact

### Product code this spec expects to touch

- `quenching/assets/bin/quenching/opensource/readiness.py` ? the trufflehog URL
- `quenching/tests/test_public_readiness.py` ? the new test and the clone URL

### Process surface this spec expects to touch

- `.agents/quenching/assets/bin/quenching/opensource/readiness.py` ? deployed mirror regenerated by `cq deploy`

## Validation

- `python3 -m unittest discover -s quenching/tests -p test_public_readiness.py` exits 0.
- The new test fails on the tree before the fix on Windows and on POSIX only for the form of the URL it asserts (`file://` + root is not `as_uri()` on Windows).

## Design

`Path(root).as_uri()` is the stdlib's single correct way to turn an absolute local path into a file URL (percent-encoding, `file:///C:/...` on Windows, `file:///...` on POSIX). `root` is already absolute where readiness builds it; `as_uri` raises on a relative path, which is the right failure rather than a malformed URL.

### Assumptions

- `root` reaching `_trufflehog` is absolute ? `## Tasks` 1.1 depends on it; the test uses an absolute temp path.

## Alternatives Considered

- Keep `"file://" + root` and replace backslashes: rejected, it leaves spaces and special characters unencoded and `file://C:/x` still has the drive as host.

## Open Decisions

- none ? the fix is fully determined by the stdlib contract.

## Risks

- A relative `root` now raises `ValueError` instead of producing a bad URL. Mitigation: callers pass the resolved repository root; the test covers the absolute case.

## Handoff

- Done: trufflehog URL via Path(root).as_uri() + test (78cc089); clone URL in test (67cdc8b). Nothing open; conclude pending.
