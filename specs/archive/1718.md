## Problem

Executable `cq knowledge validate` calls use absolute `/docs`, yielding no-bundle. Independent verification in `../resume-map-prose-verify.json`, item 1, at 719ca3e5: `cq knowledge validate /docs --json` returns `[{"code":"no-bundle","path":"/docs","message":"bundle root is not a directory"}]` (exit 1), whereas relative `docs` and the default return `[]` (exit 0). `_rooted` only roots relative paths (`plugins/quenching/assets/bin/quenching/knowledge/cli.py:59-61`).

Locations: `plugins/quenching/commands/knowledge/status.md:54-55`, `commands/knowledge/align.md:25,83,283`, `commands/knowledge/import.md:110`, `commands/align.md:55`, and `assets/references/knowledge-align/conformance.md:186`; `plugins/quenching/tests/test_align_contract.py:39` pins the absolute invocation. Related executable error: conformance line 54 cites retired `cq knowledge validate selftest`, which returns no-bundle (exit 1); the actual check is `plugins/quenching/tests/test_knowledge.py:135-155`.

Consequence: conformance can never satisfy its aligned/exit-0 criterion and status reports a broken bundle in healthy targets.

Scope: replace absolute `/docs` with relative `docs` only inside executable cq invocations; preserve documentation-root references and Glob notation. Replace the retired selftest citation with the actual check and update `test_align_contract.py`. Files: the five command/reference carriers above and the contract test. Do not change CLI path semantics or grants.

Acceptance: executable cq knowledge calls in commands and references no longer pass absolute `/docs`; conformance no longer cites `validate selftest`; documentation-root notation remains intact. `python3 -m unittest discover -s plugins/quenching/tests -p test_align_contract.py` and `bash scripts/verify_repo.sh` exit 0. S11 (1720) must follow S9 because they share status.md and test_align_contract.py.

## Proposal

- Every executable `cq knowledge validate` call in the five carriers passes relative `docs`, never absolute `/docs`.
- `conformance.md` stops citing `cq knowledge validate selftest` and cites `RetiredLogChecker` in `plugins/quenching/tests/test_knowledge.py`.
- `test_align_contract.py` pins the relative invocation.
- Documentation-root notation and Glob paths are untouched.

## Out of Scope

- Changing `_rooted` or CLI path semantics: the spec says the CLI stays as is.
- Grants and permissions: untouched.
- The `<repo>/docs` forms at conformance.md:174-175: already relative-rooted, not absolute.

## Design

- Rule: an executable `cq knowledge` argument is a repo-relative path, because `_rooted` only roots relative paths; `/docs` is documentation notation, valid only in prose.
- Assumption: the generated translate.py replace literal must change in lockstep with align.md line 25, or the translation drifts.
- Alternative weighed: teaching `_rooted` to accept `/docs`; rejected by the spec's own scope.

## Alternatives Considered

- Fix the CLI so `/docs` resolves to the repo docs: rejected, the problem statement forbids changing CLI path semantics.
