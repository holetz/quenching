## Problem

After the Codex mirror was retired (spec 1474, #1486), `plugins/quenching/README.md:345` still says the agents ship
under `plugins/quenching-codex/agents/`, a directory that no longer exists. Consequence: the product manual points
readers to a dead path. Leave the translator's own defaults (`translate.py:72,92`, `codex-adaptation.json:11`) as they
are: they describe where a translation run would write, and the owner kept the translator.

## Proposal

Corrigir a linha 345 de `plugins/quenching/README.md`: os seis agentes são entregues em `agents/` do plugin `quenching`, e o Codex não recebe mais cópia em `plugins/quenching-codex/agents/`.

## Out of Scope

- Os defaults do tradutor (`translate.py:72,92`, `codex-adaptation.json:11`): descrevem onde uma execução de tradução escreveria, e o dono manteve o tradutor.
- Regenerar `plugins/quenching-codex` ou `.agents`.

## Impact

### Standards this spec will write into docs/standards/

- none — a correção é de uma linha do manual do produto; nenhum standard é escrito.

### Product code this spec expects to touch

- `plugins/quenching/README.md` — a linha 345, na tabela do catálogo de comandos.

## Validation

`grep -n "quenching-codex" plugins/quenching/README.md` não imprime a linha 345, e `bash scripts/verify_repo.sh` sai com 0.

## Design

Edição de prosa numa célula de tabela. Troca-se a frase final "Codex receives the command and the six agents, shipped under `plugins/quenching-codex/agents/`" por uma que não cite o caminho morto (o espelho Codex foi aposentado pela spec 1474).
