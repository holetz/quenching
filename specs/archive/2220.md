## Problem

`scripts/toolchain/affected.py` (linhas 6, 229-239) seleciona testes por uma tabela de regras mais os imports diretos de cada arquivo de teste; não segue um módulo alcançado por outro. Ex.: `git/stale.py:19-20` importa `session.worktrees`, mas mudar `session/worktrees.py` seleciona 14 arquivos e não `test_git.py`. Reproduzido (scout, cópia de a3a1fedcf): quebrar `worktree_branch` (session/worktrees.py:36) para sempre devolver `None` e rodar a suíte menos os 14 selecionados → 2 falhas causadas pela quebra (`test_git.py::Stale::test_an_unregistered_worktree_is_reported_with_branch_and_size`, `test_specs_portal.py::Sessions::test_with_the_flag_only_the_fixed_fields_of_this_repo_surface`), que passam com o módulo restaurado. Estimativa (limite superior): 103 de 205 módulos têm testes alcançados só por caminho indireto.

Consequência: `python3 -m scripts.toolchain.test --affected` e `QUENCHING_TEST_SCOPE=affected bash scripts/verify_repo.sh` — o nível que fecha uma spec — ficam verdes numa regressão real; só o CI completo pega, depois do push, contra a promessa de `affected.py:67`. Direção: seguir o grafo de imports dentro do pacote, ou cair na suíte completa quando o módulo mudado é importado por outro pacote.

## Proposal

- Mudar um módulo do pacote shipped seleciona também os testes que o alcançam por import indireto (fecho transitivo reverso do grafo de imports dentro de `quenching.*`), não só os que o importam direto.
- Imports relativos e `from pkg import submódulo` entram no grafo; hoje são ignorados.
- Quando o grafo não decide (módulo de arquivo que não parseia, ou módulo importado por nome dinâmico), o seletor cai na suíte completa com razão `fail-open`.
- O caso reproduzido (`session/worktrees.py` → `test_git.py`) passa a ser selecionado, com teste de regressão.

## Out of Scope

- Reescrever a tabela `RULES` ou o que conta como `GLOBAL`: a tabela segue como piso generoso; o grafo só acrescenta.
- Seguir dependências que não são import Python (leitura de referências por `cq components read`): já cobertas por `GLOBAL`.
- Skip/xfail de qualquer teste: nunca.

## Design

Decisão do épico 2223 (2026-11-21): preferir seguir o grafo de imports dentro do pacote; cair na suíte completa é aceitável quando o grafo não decide. Nunca skip/xfail.

- `_module_of` já dá o módulo pontilhado de um arquivo shipped. Um novo `_import_graph(root)` varre `quenching/assets/bin/**/*.py` uma vez e mapeia cada módulo aos módulos conhecidos que ele importa: `import a.b`, `from a.b import c` (aresta para `a.b.c` se for módulo, e para `a.b`) e imports relativos resolvidos pelo pacote do arquivo. Só entram arestas para módulos que existem no conjunto conhecido, então o fecho não incha por prefixo.
- `_dependents(graph, modules)` calcula o fecho transitivo reverso; os testes são os que importam (direto, pela lógica atual) qualquer módulo do fecho.
- Imports dentro de funções contam (`ast.walk` já os vê). Arquivo que não parseia → fail-open completo, pois o grafo não decide.
- O fecho só aumenta a seleção; nunca remove o que a tabela ou o import direto já escolhem.

## Alternatives Considered

- Suíte completa sempre que o módulo mudado é importado por outro módulo: seguro, mas na prática quase todo módulo é, e anula o seletor.
- Instrumentar cobertura por teste: caro e frágil; descartado.

## Open Decisions

## Risks

- Imports dinâmicos (`importlib`) escapam do grafo — ACCEPTED: o repositório os usa pouco, e a tabela `RULES` continua como piso.
- Seleção maior em mudanças centrais — ACCEPTED: é o custo de a verde significar o que diz.

## Outcome

`scripts/toolchain/affected.py` agora segue imports indiretos: `select` monta o grafo de imports do pacote entregue (`quenching/assets/bin`, absolutos e relativos, `from pkg import sub` incluído) e calcula o fecho transitivo reverso dos módulos mudados antes de escolher testes. Um teste que só alcança o módulo mudado por outro módulo passa a ser selecionado. Se algum módulo do pacote não parseia, o grafo não é confiável e a seleção cai em fail-open (roda tudo). Teste de regressão em `quenching/tests/test_toolchain_affected.py` cobre o import indireto e o fail-open, visto falhar antes da implementação.

Ficou de fora: imports dinâmicos (`importlib`) e grafo fora de `quenching.*`. Revisado, sem docs emergentes a destilar; pronto para merge.
