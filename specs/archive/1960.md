## Problem

Achados da revisão do épico 1957 (main a48f1f6de), todos reproduzidos com `/tmp/claude-1000/-home-user-Projetos-quenching/260124f0-d701-4348-a403-5c070922df48/scratchpad/repro_guard3.py`.

1. **OSError escapa e vira fallback** (revisor e Codex, segurança): `codex/guard.py:98-102` (`_digest`) abre arquivos sem tratar `OSError`. `review.py:146` e `:162` só capturam `GuardError`, e `assets/bin/cq:342-349` só captura `SystemExit`. Um arquivo ilegível (`touch x && chmod 0 x`, ou `chmod 000` num arquivo marcado `assume-unchanged`, aberto a partir de `guard.py:151-154`) gera traceback e exit 1. O chamador cai no fallback em vez de receber o exit 2 `codex-git-guard`, e antes da execução sobra `.quenching/codex/<run>/` (o `rmtree` de `review.py:147` é pulado). Reprodução: `C1 escaped: PermissionError [Errno 13] Permission denied: …/a.txt`.
2. **Symlink versionado** (Codex, `guard.py:153`): um symlink rastreado e limpo (`link.json -> cache/config.json`, com `cache/` ignorado) fica fora do snapshot, então escrever por ele passa. Reprodução: `C2 equal after write through tracked symlink: True`.
3. **Symlink ignorado para diretório** (Codex, `guard.py:104`): `.claude/skills/foo -> <dir>` entra só como `link:<dir> -`, então editar `<dir>/SKILL.md` passa. Reprodução: `C3 … equal after editing target: True`.

Consequência: um Codex sob bypass consegue desligar a parada para o humano com um `chmod`, e consegue mudar configuração através de symlinks sem que a guarda veja.

**Decisão do dono delegado:**
- qualquer exceção dentro do snapshot (antes ou depois) vira exit 2 `codex-git-guard`, com a limpeza da pasta da execução no caso "antes"; vale um teste pela `main()` com um arquivo ilegível criado pelo fake;
- todo symlink da worktree (rastreado ou ignorado) cujo destino resolvido é um arquivo entra com o destino mais o hash dos bytes resolvidos;
- symlink para diretório não é percorrido (custo sem limite). O `codex-pillar.md` declara isso como risco residual, ao lado de "um comando fora da worktree ou uma chamada de rede", e o README também.

## Proposal

- Snapshot filesystem errors refuse with exit 2 and code `codex-git-guard`, before or after review, rather than allowing fallback; a before-run refusal removes the run folder.
- Every worktree symlink resolving to a file records the link target and the resolved file bytes, including clean tracked links, ignored links and targets outside the worktree.
- The standard and README explicitly disclose that directory symlinks are not traversed and remain a coverage limit.

## Out of Scope

- Recursive directory-symlink traversal: unbounded target trees would change the guard's cost and scope.
- New permissions, sandbox modes, autonomous protocols, credential policy, or a general audit-evasion search: the delegated owner authorized the concrete snapshot defects only.
- Publishing, merging and closing the spec: those remain the orchestrated conclude and stewardship phases.

## Design

Filesystem failures while collecting a review snapshot are normalized to `GuardError`, so the existing before/after refusal paths preserve the complete CLI payload. Before-run failures remove the newly-created run directory; after-run failures preserve the evidence and hand control to the human. Expected absent paths (deleted files and dangling symlinks) remain representable snapshot state.

The existing status, tracked-file flags and ignored-file enumerations supply candidate paths. Clean tracked symlinks and ignored symlinks are included independently of local-config naming. File symlinks record `os.readlink` plus the SHA-256 of the resolved bytes; external targets receive the same treatment. No directory-symlink traversal is introduced.

## Alternatives Considered

- Catch errors only at the CLI boundary: rejected because it would bypass the before-run cleanup and lose snapshot context.
- Follow directory symlinks recursively: rejected by the delegated owner's explicit bounded-cost decision.
- Hash only the link text or only dirty tracked links: rejected because writes through stable clean links would remain invisible.
