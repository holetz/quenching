## Problem

The autopilot's Liveness rule stops a worker with `TaskStop` after 20 minutes without a transcript change and no live child, judged on one reading. A worker that resumed activity, or whose child was still starting, between that reading and the stop is killed and relaunched on stale evidence, and the round record keeps no trace of what the decision rested on.

## Proposal

Make the stall a claim about the present: immediately before `TaskStop`, re-read both signals — the transcript mtime and the live-child check — and stop only when the second reading still shows the stall. Record both readings (time, mtime, child present) in the round record beside the relaunch, so a disputed stop can be audited.

## Out of Scope

- Changing the 20-minute default or `shared.autonomy.livenessMinutes`.
- Any change to the orchestrator's own waiting rules.

## Impact

### Product code this spec expects to touch

- `quenching/skills/quenching-specs/references/autopilot.md` — the Liveness invariant
- `quenching/tests/test_autonomy_prose.py` — the recheck and the recorded readings stay in the body
- `.agents/skills/quenching-specs/references/autopilot.md`, `.claude/skills/quenching-specs/references/autopilot.md` — the deployed copies

## Validation

`python3 -m unittest discover -s quenching/tests -p test_autonomy_prose.py` passes; `bash scripts/verify_repo.sh` shows no new failure, its deployed-surface lockstep included.

## Design

- One sentence added to the Liveness bullet; no new verb and no new grant: the reads are the same mtime and child checks the rule already makes.
- Precedent: equin's orchestration watch treats "quiet" as a claim about the present and rechecks it before delivery, after supervisors were told a child was quiet while it was still starting (`plugins/tasks/plugins/orchestration/plugins/watch/CLAUDE.md`).

## Alternatives Considered

- Lengthen the threshold: trades a slower recovery for the same single-reading race. Rejected.

## Open Decisions

- none — the recheck uses only signals the rule already reads.

## Risks

- A second reading adds seconds before a real stall is stopped; negligible against a 20-minute threshold.
