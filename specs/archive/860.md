## Problem

A spec `enxugar-create-e-eliminar-o-rung-hooks` (B5) reescreveu os findings de `skills.py drift`:
como nada mais é instalado, uma cópia sob `.claude/hooks/` deixou de ser dependência velha e passou
a ser **lixo legado**, então `sk-tool-behind` caiu de `error` para `warn` e `sk-tool-unwired` /
`sk-tool-absent` sumiram. Correto quanto ao significado.

O efeito colateral é no **exit code**. `exit_for()` devolve 1 só quando há severidade `error`:

```python
return 1 if any(f["severity"] == "error" for f in findings) else 0
```

Com todo finding de `drift` agora `warn`, **`drift` nunca mais sai 1** — nem quando encontra três
cópias legadas. Um conductor que gate no exit code sozinho vê sempre limpo.

**Nada está quebrado hoje**, e é por isso que isto é uma spec e não um bug urgente: os corpos de
align leem o payload `--json` e ramificam nos findings, não no exit code. Mas o contrato uniforme
que as referências enunciam — **0 ok · 1 findings · 2 refusal** — deixou de valer para este
subcomando, e a frase está escrita assim em
`assets/references/align/tool-resolution.md` §Resolving the tool, que a própria B2 acabou de criar.

**A decisão a tomar é qual das três metades ceder:**

1. **A prosa está errada** — o contrato real já era `0 ok-ou-warnings · 1 errors`, e `lint` sempre se
   comportou assim (o CLAUDE.md documenta `lint --json # exit 0 (warnings reported, not fatal)`).
   Então corrigir a redação em tool-resolution.md e onde mais ela aparecer.
2. **A severidade está errada** — uma cópia legada merece `error`, porque o hook dispara duas vezes
   por evento num repo que aceitou a oferta antiga (é o estado deste próprio repo hoje).
3. **`exit_for` precisa de um terceiro código** para "achei coisa, nada fatal" — o mais caro, e
   mexe em todos os subcomandos.

A opção 1 é a mais provável de estar certa, mas é uma decisão sobre o contrato público das três
ferramentas, então não foi tomada no conclude que a encontrou.

Encontrado na revisão de branch de `enxugar-create-e-eliminar-o-rung-hooks` (achado R6), e
registrado nas Discoveries dela.
