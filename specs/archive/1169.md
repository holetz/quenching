## Problem

O AGENTS.md declara `bash scripts/verify_repo.sh` como o gate único, que precisa sair com zero
erros. O CI roda `uv run ruff check .` num job próprio (`.github/workflows/ci.yml`, job `lint`), e o
`verify_repo.sh` não chama o ruff. Evidência de atrito: o commit `ea64a32f` ("Drop an unused
variable flagged by ruff", 2026-10-07) consertou depois um erro que o gate local deixou passar.

Consequência: um PR verde localmente fica vermelho no CI; o worker orquestrado reporta `GATE: pass`
para um branch que o CI recusa.

## Proposal

- `bash scripts/verify_repo.sh` runs `uv run ruff check .`, the same command the CI `lint` job runs, and fails the gate when ruff reports an error.
- The CI lint job and the local gate invoke the identical command line, so a green local gate cannot be red in the CI lint job.

## Out of Scope

- Changing the ruff rule set in `pyproject.toml`: the gate must match the CI, not redefine it.
- Making CI call `verify_repo.sh`: the job split in CI is deliberate and untouched.

## Impact

### Standards this spec will write into docs/standards/

- none — the gate is a script, no standard is declared.

### Product code this spec expects to touch

- `scripts/verify_repo.sh` — add the ruff check step.

## Validation

- `grep -q 'ruff check' scripts/verify_repo.sh` exits 0 afterwards (non-zero before).
- `bash scripts/verify_repo.sh` exits 0 on a tree where `uv run ruff check .` passes.

## Design

- Decision: add a `run_check "ruff" uv run ruff check .` step right after the unit-test block, using the same `uv run` form as the CI job and as the existing `uv run zensical build` step, so no new dependency path is introduced. Rule: the local gate carries every check the CI runs.
- Alternative weighed: bare `ruff check .` from PATH. Rejected: it can run a different version than the locked one the CI uses.

### Mapa de dependências

- `.github/workflows/ci.yml` (lint job) — the command to mirror; unchanged.
- `scripts/verify_repo.sh` — the only file edited; AGENTS.md describes it as the single gate and needs no edit.

## Alternatives Considered

- Document "also run ruff" in AGENTS.md: rejected, it leaves the gate able to report pass for a red CI.

## Open Decisions
