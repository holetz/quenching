## Problem

`components/commands/translate.py:615-627` (`write_tree`) lê `.generated-files.json` e faz `unlink` de `destination / rel` para cada caminho antigo, sem conferir que o caminho resolvido fica dentro do destino. Reproduzido num repositório de rascunho: `{"files":["../../victim.txt"]}` fez `cq components translate --write` apagar um arquivo dois níveis acima de `.agents`. Um manifesto `{}` sai com `KeyError: 'files'` e traceback em vez de `ct-translation-refused`.

Consequência: o manifesto é versionado e mesclável; um merge ruim ou uma PR hostil faz a próxima regeneração apagar arquivos arbitrários de quem a roda, e um manifesto danificado aborta sem achado estruturado.

## Proposal

Resolver cada caminho sob o destino e recusar, com achado nomeado e nada apagado, o que escapa, é absoluto ou passa por symlink para fora; ler o manifesto defensivamente (`files` ausente ou de tipo errado vira recusa estruturada).

## Out of Scope

O formato do manifesto, que é da C01.

## Impact

### Product code this spec expects to touch

## Validation

Testes com `../`, caminho absoluto e symlink para fora: nada apagado, recusa nomeada; manifesto `{}` dá recusa sem traceback; `bash scripts/verify_repo.sh` sai 0.

## Design

- Read the previous manifest through one helper that returns the old path set or raises `ValueError` (caught by `cmd_translate` as `ct-translation-refused`): invalid JSON, a non-object, `files` absent, or `files` neither list nor dict, or a non-string entry.
- Containment is a durable rule: a path from a manifest is untrusted input. Refuse any entry that is absolute, or whose resolved path (`(destination / rel).resolve()`) is not under `destination.resolve()`. `resolve()` follows symlinks, so a link that leaves the destination is refused by the same test.
- All entries are validated before the first `unlink`, so a refusal deletes nothing. The refusal precedes any write in `write_tree`.
- `write_tree` is called from `cmd_translate`; wrap that call so `ValueError` becomes the existing `ct-translation-refused` finding.

## Alternatives Considered

- Silently skipping bad entries: rejected, it hides a hostile or damaged manifest and still deletes the rest.
- Dropping the manifest-driven deletion for a rescan of the destination: rejected, it changes the manifest contract, which belongs to C01.

## Open Decisions

- none — the containment test and the refusal code are fixed by the Proposal.
