## Problem

`cq git worktree add --spec` recusa um branch que segue a convenção declarada: com `branchName: "feat/<ticket>-<handle-kebab>."` (o exemplo de `conventions.md:24`), `cq git worktree add --path ../wt --branch feat/PROJ-77-fixture --base main --spec 1 --json` sai exit 2 `git-worktree-spec-head-mismatch` e não cria a worktree; sem `--spec` sai 0, e `cq specs record 1 branch --set …` também (`/tmp/claude-1000/-home-unicred-Projetos-claude-quenching/a284eb01-1fc3-4a7f-ae95-abf7651b3d1b/scratchpad/review15/f2`). Onde: `plugins/quenching/assets/bin/quenching/git/worktree.py:155` reaproveita `_spec_vs_head`, que sem `branch.work` exige o nome `(?:.+/)?<id>-` (`plugins/quenching/assets/bin/quenching/git/pull.py:203`); `plugins/quenching/commands/git/branch.md:81-83` manda passar `--spec`. Consequência: num alvo cuja convenção não começa com `<id>-`, o passo `branch` para e o run autônomo morre antes da worktree. Direção: com `--spec`, só exigir que a spec exista e não tenha `branch.work` diferente.
