## Problem

A revisão opus da rodada 8 do autopilot cobriu 8b308ea22..26ad0a0d0, a épica 2007. O condutor reproduziu o achado com o `cq` do código-fonte em main 26ad0a0d0. Desde a spec 2006, `cq components cost <caminho>` mede o alvo que o caminho nomeia. Quando esse alvo não tem nenhum comando, o comando sai 0, e com `--ratchet` aprova 0 bytes. O `lint` resolve o mesmo alvo pelo mesmo `resolve_lint_targets` e recusa com `sk-no-commands`.

Evidência, em `plugins/quenching/assets/bin/quenching/components/`:

- `commands/cost.py:244-246` resolve `commands` por `resolve_lint_targets` e passa a lista a `measure_surface`. `cost.py:198-199` mede a lista vazia como superfície de 0 comandos. `cost.py:232/238` não gera finding porque `0 > teto` é falso.
- `commands/lint.py:945-950` recusa o mesmo caso com `sk-no-commands` (error).

Reprodução. Num diretório temporário fora do repo há `alvo/commands/`, vazio, e `b.json` com `{"totalBytes":100}`. O `cq` é rodado como `python3 plugins/quenching/assets/bin/cq`.

- `cq components cost <tmp>/alvo/nao-existe` imprime `components cost — <tmp>/.claude` e `0 commands / 0 bytes`, com exit 0. O caminho inexistente cai na superfície do cwd e o cabeçalho nem nomeia o alvo pedido.
- `cq components cost <tmp>/alvo --ratchet b.json` imprime `0 commands / 0 bytes` e `ratchet: 100 bytes — within ceiling`, com exit 0.
- `cq components lint <tmp>/alvo` dá `[error] no command file found under <tmp>/alvo (sk-no-commands)`, com exit 1.

Consequência: um caminho com erro de digitação, inexistente, sem `.md` ou que aponta para um arquivo que não é `.md` faz o ratchet de custo ficar verde sem ter medido nada. Um gate que dependa dele aprova uma superfície que ele não viu. Os espelhos gerados carregam a mesma linha.

Validação esperada: um teste de outro cwd em `plugins/quenching/tests/test_components_cost.py` para um caminho inexistente e para um `commands/` vazio. Os dois devem sair com erro, como no lint, inclusive com `--ratchet`. Todo arquivo de saída dos geradores deve estar declarado no `files:` da tarefa.
