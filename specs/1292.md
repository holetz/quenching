## Problem

O estreitamento do git-steward da 1279 (#1281) não bloqueia as operações perigosas (reproduzido em 2026-10-08): os bloqueios de `plugins/quenching/agents/git-steward.md:5` são padrões de texto e o argparse do `cq` aceita abreviar flags (`allow_abbrev` ligado), então `cq specs section <id> Outcome --w` foi lido como `--write`; `gh pr merge` aceita `-d`, `-s`, `-r` para `--delete-branch`, `--squash`, `--rebase`, e o glob não os pega; `Bash(git:*)` (`git-steward.md:4`) aceita `git stash`, `reset --hard`, `push --force` e `branch -D`, que a linha 17 proíbe, e `git -c alias.x='!cmd' x` executou um comando. Não está documentado se o Claude Code entende `:*` no meio de um padrão de bloqueio.

Consequência: o steward pode apagar a branch remota, fazer squash, escrever seção de spec ou rodar código pelos próprios grants, apesar da prosa.

## Proposal

**Decidido com o humano em 2026-10-08:** o git-steward passa a agir só por verbos `cq git` de argv fixo, no molde do `cq git audit` (refs resolvidas antes do uso, `--end-of-options`, `SAFE` com `core.fsmonitor` e `core.hooksPath` neutralizados); a lista de bloqueio por texto deixa de ser a defesa.

- Verbos novos para o que os passos do steward fazem (por exemplo push da branch, abertura da PR, merge com `--merge` fixo exigindo o `gh pr checks` verde da 1291, o corte da worktree do passo `branch`). O conjunto exato sai do develop, lendo `commands/git/{branch,commit,merge,pr/create,cleanup}.md`; os corpos que o steward roda passam a chamar esses verbos.
- O `tools:` de `agents/git-steward.md` perde `Bash(git:*)` e os `gh` de escrita; o `disallowedTools` por texto sai ou fica só como redundância.
- Todo parser do `cq` passa a `allow_abbrev=False` (`components/cq_calls.py:158` já lê esse atributo).
- Validação: nenhum grant do steward casa os comandos reproduzidos em `/tmp/claude-1000/-home-unicred-Projetos-claude-quenching/a284eb01-1fc3-4a7f-ae95-abf7651b3d1b/scratchpad/review8/` — `cq specs section <id> Outcome --w`, `gh pr merge -d/-s/-r`, `git -c alias.x='!cmd' x`, `git stash`, `reset --hard`, `push --force`, `branch -D`.

Complexidade alta: worker em opus.
