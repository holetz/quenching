## Problem

`quenching/tests/test_quenching_mcp_startup.py::Startup::test_initialize_and_tools_list_answer_within_one_second` asserts a 1.0 s median for `initialize` + `tools/list` and fails inside the full gate when the host runs several gates at once (load average above the core count): measured 1.74 s over 3 runs, in the branch of spec 675 and, with `QUENCHING_TEST_SCOPE=full`, on `origin/main` in a base worktree (`BASE-RED`). Alone it passes in 1.1–1.7 s, and the gate passes with `QUENCHING_TEST_WORKERS=4`. Cause: the wall-clock limit measures the host's load, not the server. Reproduction: run `QUENCHING_TEST_SCOPE=full bash scripts/verify_repo.sh` on a machine under load. Files: `quenching/tests/test_quenching_mcp_startup.py`.
