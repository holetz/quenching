## Problem

Observado pelo runner da 488 (épico 515, 2026-11-25), não reproduzido: o Copilot do VS Code lê servidores MCP de `.vscode/mcp.json`, enquanto o `cq deploy` escreve `.mcp.json`. Seria a causa provável de o spec-orchestrator e o verifier terem rodado sem as tools `specs_*`/`git_*` no épico 453 ("MCP quenching não montado", ver 488). A 488 corrigiu a projeção de `tools:` dos agentes, mas não toca settings (fora da autorização do épico 515).

Próximo passo: reproduzir no VS Code (fora do alcance desta sessão, que roda sem o VS Code) e decidir se o deploy projeta `.vscode/mcp.json` — uma decisão de superfície que executa código, para o humano.
