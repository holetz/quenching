## Problem

quenching/references/specs-develop/artifacts.md:315 (§Execution metadata) manda declarar `quenching/README.md` em `files:` e regenerá-lo com `cq proof readme --write` em toda task que cria um módulo em quenching/tests/, porque "the generated proof README counts the modules, so it goes stale (pf-readme-stale)". A regra faz o develop declarar um arquivo que nenhuma task muda.
