# Reference

Exact detail, optimized for Ctrl-F: the full command surface, this repository's own local
automation, and the projected vocabulary. Nothing here teaches — that is what
[tutorials](../tutorials/index.md) and [concepts](../explanation/index.md) are for; these pages
answer precise questions with stable headings.

## Pages

- [Command catalog](commands.md) — all forty-one `/quenching:*` commands by front, one line
  each, plus the `cq` rail's exit-code contract.
- [Automation registry](automation.md) — this repository's **own** local Claude Code command
  surface, derived from `.claude/commands/`; its table is regenerated by
  `cq components registry reindex`.
- [Glossary](glossary.md) — the published vocabulary, projected from the canonical bundle
  glossary; every term also renders as an `<abbr>` tooltip across the site.
