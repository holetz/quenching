# Review context

This repository keeps its standards in `/docs/standards/` and its vocabulary in `/docs/glossary.md`.

When reviewing a change, read `/docs/standards/index.md` and apply every standard whose
`resource:` covers a changed file; cite the standard's path in each finding. When a change
contradicts a standard, say which one and why.
