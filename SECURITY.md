# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the repository's **Security** tab, choose
**Report a vulnerability**, and describe what you found, the affected version and the steps to
reproduce it. The report is visible only to the maintainers.

You can expect an acknowledgement of the report, an assessment of its impact, and a fix or a
mitigation published in a release. We ask that you keep the details private until a fix is
available, and we credit reporters who want to be credited.

## Supported versions

Only the latest release of the plugin receives security fixes. See
[CHANGELOG.md](CHANGELOG.md) for the release history.
