# Tags

Small status vocabulary: stage marks, chips, priority and the runner's verdict.

`.pri.p1` is solid ink and `.pri.p2` outlined; P3 and P4 are plain text. Priority uses no colour, because the accent is taken. `.run` shows the runner's word and the verifier's, in pt-BR, and `.run.bad` is a failed step. `.chip.hot` is `espera você`, and health uses `.chip.ok`, `.info`, `.warn` and `.bad` as `epicHealth` does.
