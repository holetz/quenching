# Icons

The authored icon set: 16px, 1.5 stroke, round caps, `currentColor`.

Draw with `<svg class="i" viewBox="0 0 16 16">` and the path from `ICONS` in `build.py`, through `createElementNS` in the portal. Decorative icons carry `aria-hidden`; an icon-only button carries `aria-label`. Replaces the glyphs `◐`, `?`, `×`, `▲` and `▼` (R17).
