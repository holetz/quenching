# GanttChart

The server's schedule as SVG, built with `createElementNS`.

The page places `earliestStart` and `earliestFinish` and computes no date. Bars take `st-<stage>`, `critical` adds an ink outline, `slip` a dashed one. Today is the only heated line. Offer the same data in a `<caption>` table for assistive technology. Undated specs go to a table below (D6). Refinement R12.
