# Buttons

Actions, from the view's one primary down to a quiet ghost.

`button.primary` once per view. `button.heat` for a row action that needs the human. Default `button` for a safe alternative beside a primary. `.ghost` for everything frequent and quiet. `.small` in rows and toolbars, `.icon` for a square icon button with `aria-label`, `.link` inside prose. A toggle uses `aria-pressed`, filled in `ink`. Disabled is neutral, with the reason in `title`. Count badges are `.count`, and `.count.hot` is the only heated one.
