# TopBar

The one-row shell header: brand, seven destinations, search, theme, help, send and capture.

The consumer provides the current view (`aria-current="page"`) and two counts. The current item is `ink` with a 2px rule, never the accent. `Sessões` and `Chat` exist only when the server turned them on. `Enviar` exists only with pending writes, as `button.heat`. Source: `index.html` `.top`. Refinement R1.
