# Stages

The seven derived stages of a spec, each with a mark, a chip and a lane rule.

Use the mark (`.stage` under `[data-stage]`) by default, the chip (`.chip.stage-*`) only in a spec's head, the rule on a lane's `.col-head`. The consumer provides the stage key and the pt-BR word from `STAGE_PT`. Never show the key itself, and never set text in a `stage-*` colour.
