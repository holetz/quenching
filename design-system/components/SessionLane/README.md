# SessionLane

One live session: who it is, what it is doing, what it did in the last hour.

Identity is the branch, the worktree and a short session id, so that sessions on one checkout can be told apart (D9). The radar is 60 bars of per-minute activity, in `muted`, because activity is not a state. Sub-agents hang beneath as tracks. Exists only under `--sessions`. Refinement R13.
