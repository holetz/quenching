# Glossary

One entry per term, alphabetically sorted: `* **<Term>** — <one-sentence definition>`.

* **Cursor** — an opaque token that marks where the next page starts.
* **Page** — a fixed-size slice of a result list.
* **Page size** — something about how many lines.
