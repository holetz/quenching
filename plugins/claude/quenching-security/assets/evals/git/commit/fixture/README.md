# Eval fixture — git/commit

A small repository for the `/quenching-specs:git:commit` suite. `setup.sh` declares the commit
subject convention in `.claude/quenching.json`, commits it, and then leaves the index the case
needs: a staged change beside an unstaged one, an unstaged change alone, or a staged change the
case must not commit.
