# `communications/archive/` — issued communications

The **concrete communications already issued**, preserved as a record. The skeleton ships no
communication — this home starts empty; the repo records here what it sent.

## How to organize

- **One file per communication**, dated in the name: `YYYY-MM-DD-<scope>-<slug>.md`
  (e.g. `2026-07-06-pipeline-sales-incident.md`). Most recent listed first.
- Each carries `type: communication`, `audience: human`, `authority: background` — it is a
  record, **never** a current contract.
- If the message became a permanent rule, it **distills into
  [standards/](/docs/standards/index.md)**; the communication stays here as a record only.
