# `communications/archive/` — issued communications

The **concrete communications already issued**, preserved as a historical record. The
skeleton does **not** ship any communication — this home starts empty; the repo
records here what it sent.

## How to organize

- **One file per communication**, dated in the name: `YYYY-MM-DD-<scope>-<slug>.md`
  (e.g.: `2026-06-29-pipeline-sales-incident.md`). Most recent at the top.
- **Which** communications exist is REPO content — as with `guides/`, the package
  installs the **structure**, not the **content**.
- Born `audience: human` / `authority: background` — it is a record, **never**
  a current contract. If the message became a permanent rule, it **distills into
  `standards/`**; the communication stays here as historical record only.
