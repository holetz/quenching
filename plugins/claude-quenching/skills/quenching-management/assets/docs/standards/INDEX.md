# Index of `standards/`

Lists exactly the current/active docs that exist in `standards/`, with a short
directive and relative link. **Keep in sync:** an index that lists docs that do not
exist (or omits docs that exist) is Drifted and misleads the agent. One standard
per file; kebab-case without accents.

The preamble above (and the "Row model") is **authored** — free to edit. The
**tables between the `BEGIN/END GENERATED` markers are DERIVED**: regenerated from disk
by the `quenching-standards` skill (scans `standards/**/*.md`, reads
`title:`/`summary:`/`updated:`/`authority:`), **do not edit the generated zone by hand**
("X defines Y" rule — this makes structural drift impossible by construction).

## Row model

The generated zone is **grouped by subject subfolder**; each subfolder is a small
table, one row per doc — `Doc` (relative link, `title`) × `Covers` (the doc's
`summary:`, now **mandatory** for a standards bundle; `→ title` is a defensive
fallback for a malformed doc):

```
### naming/
| Doc | Covers |
| --- | --- |
| [columns.md](naming/columns.md) | <the doc's summary: — what it covers in one sentence> |
```
