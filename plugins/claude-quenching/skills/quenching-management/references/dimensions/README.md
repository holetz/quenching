the dimension you are scoring, instead of loading the whole catalog). Each file carries the
six fields — Purpose · How "good" looks · Detection · Smells · Remediation · Payload.

canonical-`docs/`-names exception, the 6-field explanation, the scoring summary) lives in
the index [../dimensions-template.md](../dimensions-template.md) — **not** repeated here.
