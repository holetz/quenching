---
description: Convert a Claude Code native plan file into a specs/ plan, so it can be built and archived
argument-hint: [path-to-plan-file]
---

Use the Skill tool to invoke `claude-quenching:quenching-specs-plan-from-claude`, passing
`$ARGUMENTS` (an optional path to a Claude Code plan file; omit to pick from ~/.claude/plans) as
the skill's input.
